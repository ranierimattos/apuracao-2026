# Apuração Presidente 2026

Painel em tempo real da apuração do 1º turno para presidente do Brasil, com mapa por regiões, os dois primeiros colocados, percentual apurado e projeção a 100%.

Dados públicos do TSE (resultados.tse.jus.br) e malha do IBGE. Projeção é uma simulação, não resultado oficial.

Desenvolvido por Ranieri de Mattos, com Claude Code, Sonnet 5.5 by Anthropic.
